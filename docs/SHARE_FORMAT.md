# Формат ссылок на маршруты

Маршрут целиком упаковывается в ссылку, поэтому для обмена не нужен сервер:
ссылку можно отправить в мессенджер, превратить в QR-код или открыть в браузере.
Этот формат читают приложение для iOS (`Core/Sources/RecorridoCore/ShareCodec.swift`),
веб-страница `docs/index.html`, и его же должна читать будущая версия для Android.

## Ссылки

| Вид | Пример | Что откроет |
| --- | --- | --- |
| Веб-ссылка | `https://artyomvorobiov.github.io/recorrido/#AZ1Y…` | Страницу с картой в любом браузере; с неё — приложение |
| Ссылка приложения | `recorrido://import#AZ1Y…` | Сразу приложение |
| Параметр запроса | `…/?r=AZ1Y…` | То же, что фрагмент; на случай, если `#` потерялся |

Полезная нагрузка (`AZ1Y…`) стоит во фрагменте после `#`: браузер не отправляет фрагмент
на сервер, так что маршрут остаётся между отправителем и получателем.
Фрагмент может начинаться с `r=` — его нужно отбросить.

Другие ссылки приложения: `recorrido://trip` (текущая прогулка), `recorrido://route/<id>`
(маршрут из каталога или библиотеки), `recorrido://generate` (генератор маршрута).

## Полезная нагрузка

```
payload = base64url( version + body )
```

- `base64url` — Base64 с алфавитом `-` и `_` вместо `+` и `/`, без `=` в конце (RFC 4648, §5).
- `version` — один байт:
  - `0` — `body` это JSON в UTF-8;
  - `1` — `body` это тот же JSON, сжатый **raw DEFLATE** (RFC 1951) — без заголовка zlib и без контрольной суммы.
- Приложение пишет версию `1`, если сжатие дало выигрыш, иначе `0`. Читать нужно обе.
- Неизвестная версия означает, что маршрут сохранён более новым приложением: покажите просьбу обновиться.

## JSON

Короткие ключи экономят место в ссылке и QR-коде. Необязательные поля можно пропускать.

```json
{
  "v": 1,
  "t": "Суздаль за один день",
  "s": "Кремль, монастыри и деревянное зодчество",
  "c": "Суздаль",
  "cc": "Россия",
  "e": "🥒",
  "a": "Маша",
  "l": "ru",
  "o": "suzdal-day",
  "d": [
    {
      "t": "Пешком по центру",
      "p": [
        { "n": "Суздальский кремль", "y": 56.41506, "x": 40.44051, "k": "castle", "m": 60,
          "d": "Древнейшая часть города…", "tp": "Поднимитесь на вал…",
          "w": "Суздальский кремль", "wl": "ru" },
        { "n": "Кидекша", "y": 56.425, "x": 40.52779, "k": "church",
          "am": "car", "an": "Около 5 км — 10 минут на машине или такси" }
      ]
    }
  ]
}
```

### Маршрут

| Ключ | Тип | Обяз. | Значение |
| --- | --- | --- | --- |
| `v` | число | да | Версия схемы JSON, сейчас `1` |
| `t` | строка | да | Название |
| `s` | строка | | Краткое описание |
| `c` | строка | да | Город |
| `cc` | строка | | Страна |
| `e` | строка | | Эмодзи маршрута (по умолчанию 🗺️) |
| `a` | строка | | Автор |
| `l` | строка | | Язык текстов: `ru`, `en` |
| `o` | строка | | Идентификатор исходного маршрута (например, из каталога) |
| `d` | массив | да | Дни |

### День

| Ключ | Тип | Обяз. | Значение |
| --- | --- | --- | --- |
| `t` | строка | | Название дня |
| `p` | массив | да | Остановки по порядку |

### Остановка

| Ключ | Тип | Обяз. | Значение |
| --- | --- | --- | --- |
| `n` | строка | да | Название |
| `y` | число | да | Широта (5 знаков после точки ≈ 1 м) |
| `x` | число | да | Долгота |
| `d` | строка | | Описание |
| `tp` | строка | | Совет |
| `k` | строка | | Тип места (см. ниже), по умолчанию `other` |
| `m` | число | | Минут на месте; если нет — значение по умолчанию для типа |
| `ad` | строка | | Адрес |
| `w` | строка | | Название статьи Википедии |
| `wl` | строка | | Язык Википедии (`ru`, `en`, …) |
| `i` | строка | | Ссылка на картинку (Wikimedia) |
| `am` | строка | | Как добраться от предыдущей остановки (см. ниже), по умолчанию пешком |
| `an` | строка | | Подсказка о дороге: «Около 5 км — 10 минут на такси» |
| `r` | строка | | Идентификатор точки из каталога (`suzdal-kremlin`): приложение получателя само подставит полный рассказ гида |
| `st` | строка | | Рассказ автора об этой точке, абзацы через пустую строку (только у точек не из каталога) |
| `lf` | массив строк | | Что поискать глазами на месте (только у точек не из каталога) |

**Типы мест** (`k`) и минуты по умолчанию: `museum` 90, `palace` 75, `castle` 75, `park` 45,
`nature` 45, `food` 45, `market` 40, `district` 40, `church` 25, `street` 25, `landmark` 20,
`theater` 20, `viewpoint` 15, `square` 15, `bridge` 10, `monument` 10, `other` 20.

**Способы передвижения** (`am`): `walk`, `bike`, `metro`, `tram`, `bus`, `train`, `ferry`,
`funicular`, `cableCar`, `transit`, `car`.

### Правила совместимости

- Незнакомые ключи игнорируются.
- Незнакомый тип места читается как `other`, незнакомый способ передвижения — как пешком.
- Идентификаторы остановок в ссылку не попадают: получатель создаёт свои.

## Сколько текста помещается

Приложение умеет три уровня подробности:

- **полный** — всё, включая описания, советы, картинки и рассказы автора (для ссылок и общей ленты);
- **краткий** — описания обрезаны до 160 символов, рассказы до 280, подсказки о дороге до 80;
- **минимальный** — только названия, координаты, типы и способы передвижения.

Для QR-кода выбирается самый подробный уровень, при котором ссылка короче 2800 байт.

## Примеры декодирования

### JavaScript (браузер)

```js
async function decodeRoute(payload) {
  let base64 = payload.replace(/-/g, "+").replace(/_/g, "/");
  while (base64.length % 4) base64 += "=";
  const bytes = Uint8Array.from(atob(base64), (c) => c.charCodeAt(0));
  let body = bytes.subarray(1);
  if (bytes[0] === 1) {
    const stream = new Blob([body]).stream().pipeThrough(new DecompressionStream("deflate-raw"));
    body = new Uint8Array(await new Response(stream).arrayBuffer());
  }
  return JSON.parse(new TextDecoder().decode(body));
}
```

### Python

```python
import base64, json, zlib

def decode_route(payload):
    data = base64.urlsafe_b64decode(payload + "=" * (-len(payload) % 4))
    body = data[1:] if data[0] == 0 else zlib.decompress(data[1:], -15)  # -15 = raw DEFLATE
    return json.loads(body)

def encode_route(route):
    deflater = zlib.compressobj(9, zlib.DEFLATED, -15)
    body = deflater.compress(json.dumps(route, ensure_ascii=False).encode()) + deflater.flush()
    return base64.urlsafe_b64encode(bytes([1]) + body).decode().rstrip("=")
```

### Kotlin (Android)

```kotlin
fun decodeRoute(payload: String): String {
    val bytes = Base64.decode(payload, Base64.URL_SAFE or Base64.NO_PADDING or Base64.NO_WRAP)
    val body = bytes.copyOfRange(1, bytes.size)
    if (bytes[0].toInt() == 0) return body.toString(Charsets.UTF_8)
    val inflater = Inflater(true) // true = raw DEFLATE, без заголовка zlib
    inflater.setInput(body)
    val out = ByteArrayOutputStream()
    val buffer = ByteArray(4096)
    while (!inflater.finished()) {
        val count = inflater.inflate(buffer)
        if (count == 0 && inflater.needsInput()) break
        out.write(buffer, 0, count)
    }
    inflater.end()
    return out.toString(Charsets.UTF_8)
}
```
