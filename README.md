# Recorrido — маршруты по малым городам

Приложение для iPhone с маршрутами по городам. Главная идея — малые города России:
Суздаль, Переславль-Залесский, Коломна, Плёс, Мышкин и другие, куда едут на день и
где интересное часто стоит за городом. По малому городу маршрут ведёт пешком,
а до монастыря или усадьбы в паре километров — на машине или такси. По большому городу
маршрут рассчитан на два-три дня, каждый день в своём районе.

## Что умеет приложение

- **Готовые маршруты.** 12 малых городов (Суздаль, Переславль-Залесский, Коломна,
  Ростов Великий, Углич, Сергиев Посад, Плёс, Мышкин, Боровск, Муром, Выборг, Тобольск)
  и три больших: Москва и Казань на два дня, Петербург на два дня плюс поездка в Петергоф
  на «Метеоре». У каждой точки есть описание, совет, время на осмотр и подсказка, как
  добраться от предыдущей: пешком, на машине, на теплоходе, на метро.
- **Маршрут для любого города.** Генератор за полминуты собирает маршрут по статьям
  Википедии: находит достопримечательности, отсеивает лишнее, сам решает, нужна
  короткая прогулка, день или несколько дней, и строит порядок обхода. Если в маленьком
  городе мало мест, он смотрит на 20 км вокруг и добавляет поездки на машине.
- **Свои маршруты.** Можно создать маршрут с нуля или переделать любой готовый:
  добавить точки поиском или на карте, поменять порядок, разбить по дням.
- **Обмен маршрутами.** Ссылка, QR-код, файл `.recorrido` (AirDrop, Telegram) или картинка
  с картой для сторис. Весь маршрут хранится в самой ссылке — сервер не нужен.
  Ссылка открывается в приложении, а у кого его нет — на веб-странице с картой.
- **Режим прогулки.** Карта с вашим положением и расстоянием до следующей точки,
  кнопка «Я здесь». Когда вы подходите к точке, приложение само включает аудиогид
  (он читает описание вслух), а если телефон в кармане — присылает уведомление.
  Live Activity на экране блокировки и в Dynamic Island с кнопкой отметки.
- **Виджет.** На домашнем экране (три размера) и на экране блокировки: следующая точка
  прогулки и прогресс, а без прогулки — «Маршрут дня».
- **Паспорт.** Штамп за каждый пройденный город и список недавно посещённых мест.
- Русский и английский интерфейс, тексты каталога на обоих языках.

## Что нужно

- **Mac с Xcode 16 или новее** (Xcode бесплатен в Mac App Store; проект проверен на Xcode 16.4 и 26.3).
- **iPhone с iOS 17 или новее** — или симулятор, который входит в Xcode.
- **Apple ID.** Чтобы запускать приложение на своём телефоне, хватит обычного бесплатного.
  Для публикации в App Store нужна платная программа Apple Developer Program (99 $ в год).

## Шаг 1. Скачать проект

Код лежит в ветке `claude/wonderful-carson-jdg2sj`. Проще всего влить её в `main` через
pull request на GitHub, а потом скачать проект:

```bash
git clone https://github.com/artyomvorobiov/recorrido.git
cd recorrido
```

(Или на странице репозитория: **Code → Download ZIP** и распаковать.)

## Шаг 2. Запустить в симуляторе

1. Откройте файл `Recorrido.xcodeproj` двойным щелчком.
2. Наверху окна Xcode выберите схему **Recorrido** и симулятор, например **iPhone 16**.
3. Нажмите **⌘R** (или треугольник «Run»). Первая сборка занимает пару минут.

Чтобы проверить режим прогулки в симуляторе, задайте ему местоположение:
в меню симулятора **Features → Location → Custom Location…** введите координаты точки
маршрута (они есть в файлах `Shared/Catalog/city-*.json`).

## Шаг 3. Запустить на своём iPhone

1. **Добавьте Apple ID в Xcode:** Xcode → Settings → Accounts → «+» → Apple ID.
2. **Задайте свой идентификатор приложения.** В левой панели нажмите на проект
   **Recorrido** → вкладка **Build Settings** → в поиске наберите `RECORRIDO_BUNDLE_PREFIX`
   → замените `com.artyomvorobiov` на что-то своё и уникальное, например `com.ivanova.masha`.
   Из этого префикса собираются идентификаторы приложения, виджета и группы приложений.
3. **Выберите команду подписи.** Для каждой из двух целей — **Recorrido** и
   **RecorridoWidgetExtension** — откройте вкладку **Signing & Capabilities** и в поле
   **Team** выберите свой Apple ID (Personal Team).
4. **Только для бесплатного Apple ID:** бесплатная подпись не поддерживает App Groups.
   В обеих целях на той же вкладке удалите блок **App Groups** (крестик справа от названия).
   Приложение будет работать полностью, а виджет вместо текущей прогулки будет показывать
   «Маршрут дня». С платной учётной записью ничего удалять не нужно.
5. **Подключите iPhone** кабелем, на телефоне нажмите «Доверять этому компьютеру».
   Включите режим разработчика: **Настройки → Конфиденциальность и безопасность →
   Режим разработчика**, телефон перезагрузится.
6. В списке устройств наверху Xcode выберите свой iPhone и нажмите **⌘R**.
7. При первом запуске с бесплатным Apple ID iPhone скажет, что разработчику не доверяют:
   **Настройки → Основные → VPN и управление устройством** → ваш Apple ID → **Доверять**.

Приложение, подписанное бесплатным Apple ID, работает 7 дней — потом снова подключите
телефон и нажмите ⌘R. С платной учётной записью такого ограничения нет.

## Шаг 4. Виджет и Live Activity

- **Виджет:** долгое нажатие на домашний экран → «Изменить» → «Добавить виджет» → Recorrido →
  выберите размер. Так же добавляются виджеты на экран блокировки.
- **Live Activity** появляется сама, когда вы начинаете прогулку кнопкой «Старт» на экране
  маршрута. Если её нет — проверьте **Настройки → Recorrido → Live Activity**.
- В настройках приложения (вкладка «Паспорт» → значок настроек вверху) можно включить
  слежение за прогулкой в фоне, уведомления о прибытии, автоматический аудиогид
  и выбрать язык маршрутов.

## Шаг 5. Включить веб-страницу для ссылок

Ссылки, которыми делятся из приложения, ведут на страницу
`https://artyomvorobiov.github.io/recorrido/`. Она показывает маршрут на карте даже
без приложения и предлагает открыть его в Recorrido. Чтобы она заработала:

1. Влейте ветку в `main`.
2. На GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка **main**, папка **/docs** → **Save**.
3. Через пару минут страница откроется по адресу выше.

Если репозиторий будет под другим именем или аккаунтом, поменяйте адрес `webViewerURL`
в `Recorrido/App/AppConfig.swift` и константу `REPO` в `docs/index.html`.

## Шаг 6. Публикация в App Store

Когда приложение будет готово для других людей:

1. Вступите в [Apple Developer Program](https://developer.apple.com/programs/) (99 $ в год).
2. В [App Store Connect](https://appstoreconnect.apple.com) → **Apps → «+» → New App** создайте
   приложение с идентификатором `<ваш префикс>.recorrido`.
3. В Xcode выберите устройство **Any iOS Device (arm64)** → **Product → Archive** →
   **Distribute App → App Store Connect → Upload**.
4. Через **TestFlight** раздайте сборку друзьям и проверьте на реальных прогулках.
5. Для отправки на проверку подготовьте скриншоты, описание и ключевые слова.
   Политика конфиденциальности уже есть: `https://artyomvorobiov.github.io/recorrido/privacy.html`.
   В разделе App Privacy укажите, что данные не собираются: всё хранится на телефоне,
   а Википедия и Apple Maps получают только запросы для поиска мест и маршрутов.
6. В заметках для проверяющих объясните фоновую геолокацию: она работает только во время
   прогулки, чтобы отмечать прибытие на точки и обновлять Live Activity, и выключается
   в настройках приложения.

## Как устроен проект

```
Recorrido.xcodeproj          проект Xcode: приложение и расширение-виджет
Recorrido/                   приложение (SwiftUI)
  App/                       точка входа, общее состояние, хранилище маршрутов
  Explore/                   каталог городов и маршрутов
  Route/                     карточка маршрута, карта, точки
  Generator/                 генератор маршрута для любого города
  Library/                   «Мои маршруты» и редактор
  Trip/                      режим прогулки
  Sharing/                   ссылки, QR-код, файл, картинка
  Passport/                  штампы, статистика, настройки
  Services/                  геолокация, маршруты Apple Maps, аудиогид, Википедия
RecorridoWidget/             виджет и Live Activity
Shared/                      общее для приложения и виджета
  Catalog/city-*.json        каталог: города и маршруты на двух языках
  Localizable.xcstrings      переводы интерфейса
Core/                        логика без интерфейса (Swift Package): модели, планировщик,
                             генератор, формат ссылок, разбор каталога, тесты
docs/                        веб-страница для ссылок, политика конфиденциальности,
                             описание формата ссылок
scripts/                     проверка каталога и API Википедии
.github/workflows/           сборка и тесты на GitHub Actions
```

Код в `Core/` не зависит от iOS: его можно проверять командой `swift test` на Mac,
и он же — основа для будущей версии на Android.

## Как добавить город

Каждый город — отдельный файл `Shared/Catalog/city-<id>.json`. Приложение подхватывает
новые файлы само, ничего регистрировать не нужно. Минимальный пример:

```json
{
  "city": {
    "id": "zaraysk",
    "name": {"ru": "Зарайск", "en": "Zaraysk"},
    "region": {"ru": "Московская область", "en": "Moscow Oblast"},
    "country": {"ru": "Россия", "en": "Russia"},
    "summary": {"ru": "Не меньше 60 знаков о том, чем город интересен…", "en": "…"},
    "gettingThere": {"ru": "Как доехать из Москвы…", "en": "…"},
    "coordinate": [54.7613, 38.8836],
    "emoji": "🏯",
    "size": "small",
    "tags": ["near-moscow"],
    "wiki": {"ru": "Зарайск", "en": "Zaraysk"}
  },
  "routes": [
    {
      "id": "zaraysk-day",
      "title": {"ru": "Зарайск за день", "en": "Zaraysk in a day"},
      "summary": {"ru": "…", "en": "…"},
      "emoji": "🏯",
      "tags": ["walk"],
      "days": [
        {
          "stops": [
            {
              "id": "zaraysk-kremlin",
              "title": {"ru": "Зарайский кремль", "en": "Zaraysk Kremlin"},
              "coordinate": [54.7570, 38.8812],
              "category": "castle",
              "visit": 60,
              "details": {"ru": "Не меньше 60 знаков…", "en": "…"},
              "tip": {"ru": "Необязательный совет", "en": "An optional tip"},
              "wiki": {"ru": "Зарайский кремль"}
            }
          ]
        }
      ]
    }
  ]
}
```

Правила, которые проверяют тесты:

- все тексты — на русском и английском; описание города и точек — не короче 60 знаков;
- в каждом дне не меньше трёх точек; идентификаторы точек и маршрутов уникальны,
  маршрут начинается с идентификатора города;
- точки не дальше 80 км от города; пешие переходы не длиннее 4,5 км — для дальних
  укажите `"arrival": {"mode": "car", "note": {"ru": "…", "en": "…"}}`
  (`walk`, `car`, `bus`, `train`, `ferry`, `metro`, `tram`, `bike`…);
- типы точек (`category`): `landmark`, `museum`, `church`, `palace`, `castle`, `park`,
  `viewpoint`, `square`, `street`, `bridge`, `monument`, `market`, `theater`, `district`,
  `nature`, `food`, `other`.

Проверка: `swift test --package-path Core` на Mac. Сверка названий статей и координат
с Википедией — `python3 scripts/validate_catalog.py` (нужен интернет); то же самое делает
GitHub Actions при каждом изменении каталога и подсказывает точные координаты.

## Тесты и сборка

```bash
swift test --package-path Core                                   # логика и каталог
RECORRIDO_LIVE=1 swift test --package-path Core --filter LiveGeneratorTests   # генератор на живой Википедии
```

При каждом изменении GitHub Actions (`.github/workflows/ios.yml`) собирает приложение
с виджетом на Xcode 16.4 и 26.3 и прогоняет тесты, а `content.yml` сверяет каталог
с Википедией.

## Как работает генератор

1. Ищет статьи Википедии с координатами в радиусе 10 км (для большого города — ещё
   и самые известные места по всему городу).
2. Отбирает то, что похоже на достопримечательность: храмы, музеи, крепости, усадьбы,
   смотровые, парки. Станции, школы, события, сёла и заказники отбрасывает.
3. Оценивает каждое место по объёму статьи и удалённости. Если статей меньше 450 —
   это малый город; если интересного в нём мало, поиск расширяется до 20 км вокруг.
4. Решает длину поездки: несколько часов, день или 2–3 дня.
5. Набирает места в бюджет времени, делит их по дням так, чтобы каждый день был в своём
   районе, и выбирает порядок обхода с кратчайшей дорогой. Длинные переходы становятся
   поездками на машине или транспорте — в зависимости от выбранного способа передвижения.

## Версия для Android

Что можно взять без переделки:

- каталог `Shared/Catalog/*.json` — тот же формат;
- формат ссылок (`docs/SHARE_FORMAT.md`) — ссылки и QR-коды будут открываться
  на обеих платформах, а веб-страница уже работает для всех;
- логику из `Core/` (около 3000 строк без зависимостей от iOS) — её стоит перенести
  на Kotlin один в один, тесты подскажут, что всё совпадает.

Стек для Android: Kotlin + Jetpack Compose, карта MapLibre или osmdroid (OpenStreetMap),
виджет на Jetpack Glance, вместо Live Activity — постоянное уведомление прогулки.
